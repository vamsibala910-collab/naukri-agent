# AI Resume Automation Agent

## Overview

AI Resume Automation Agent is a Python-based automation project that updates resume content dynamically, converts the updated resume into PDF format, and automatically uploads it to Naukri.

## Features

* Dynamic resume modification based on date conditions
* Automatic certification content updates
* Automatic date updates
* DOCX to PDF conversion
* Persistent browser session management
* Automatic resume upload to Naukri
* End-to-end workflow execution through a single agent script

## Tech Stack

* Python
* Playwright
* python-docx
* docx2pdf
* Git & GitHub
* Windows Task Scheduler

## Project Structure

```text
agent.py
resume_modifier.py
pdf_converter.py
uploader.py
resumes/
.gitignore
```

## Workflow

1. Modify resume content
2. Update certification section
3. Update current date
4. Convert DOCX to PDF
5. Upload resume to Naukri
